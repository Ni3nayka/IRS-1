# OV9732 USB-модуль камеры с двойной линзой, распознавание лиц и определение глубины F0T1

https://sl.aliexpress.ru/p?key=WDCQ32F

Камера рабочая, подключается как стандартная веб-камера, в том числе на Linux. Выдает одной картинкой сразу два кадра, по функционалу все окей. Но есть крайне неприятный нюанс: два компонента на плате очень сильно греются (60 градусов), соответственно именно во время чтения камеры. Сколько проработает в таком режиме непонятно
